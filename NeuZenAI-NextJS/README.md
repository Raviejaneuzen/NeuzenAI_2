# NeuZenAI - Next.js Website

This is the Next.js version of the NeuZenAI website, converted from the original React application.

## Features

- **Modern Next.js Architecture**: Built with Next.js 14 for optimal performance and SEO
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **AI-Focused Content**: Comprehensive AI solutions and services showcase
- **Product Showcase**: Interactive product pages with background images
- **Industry Solutions**: Dedicated pages for different industry verticals
- **Service Details**: In-depth service descriptions and features
- **Contact Forms**: Interactive contact and inquiry forms
- **Professional UI**: Clean, modern design with smooth animations

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS + Custom CSS
- **Icons**: Lucide React
- **Language**: JavaScript
- **Deployment**: Vercel-ready

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd NeuZenAI-NextJS
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
